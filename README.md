# Case Study: Bellabeat Fitness Data Analysis
**Author:** [Your Name]
**Date:** April 2026

## 1. Ask
**Business Task:** Analyze smart device usage data to identify growth opportunities for the Bellabeat app and provide high-level recommendations for marketing strategy.

## 2. Prepare
**Data Source:** This analysis utilizes the FitBit Fitness Tracker Data (CC0: Public Domain), made available via Kaggle.
**Integrity:** The data includes minute-level output for physical activity and sleep monitoring for thirty eligible Fitbit users.

## 3. Process
**Tools Used:** SQL (BigQuery) for data cleaning and transformation; Google Sheets for visualization.
**Key Steps:** * Converted date strings to YYYY-MM-DD format.
* Merged daily activity and sleep tables on User ID.
* Filtered for consistency to ensure data integrity across 31 days.

## 4. Analyze & Share
*See the uploaded visualizations in this repository for full details.*

### Key Finding 1: The Evening Rush
Activity peaks between 5:00 PM and 7:00 PM. 
* **Recommendation:** Deploy push notifications at 4:30 PM to encourage evening engagement.

### Key Finding 2: The Sunday Dip
Users are significantly less active on Sundays.
* **Recommendation:** Introduce "Sunday Reset" challenges to incentivize weekend consistency.

### Key Finding 3: The Sleep Paradox
Analysis shows a weak negative correlation between daily steps and sleep duration.
* **Recommendation:** Shift marketing from "exercise more to sleep better" to "personalized sleep hygiene."

## 5. Act (Conclusion)
Bellabeat has a unique opportunity to position itself not just as a tracker, but as a wellness coach that understands the nuances of a woman's daily rhythm.
